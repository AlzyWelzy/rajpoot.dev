  \item Built \textbf{GitHub Actions} pipelines that gate on pytest, then build

        OTel Collector and Grafana Alloy into \textbf{Prometheus}, Loki and

  \item Split background work across \textbf{Celery} workers on
        \textbf{RabbitMQ} and Redis (handlers, relay, jobs, billing queues plus
        Beat), with late-ack and worker-lost requeue so no provisioning or
        billing task is silently dropped.
  \item Built an OAuth2/OpenID authorization server and \textbf{FastAPI}
        gateway to \textbf{Apache CloudStack} for VMs, volumes, networks and
        templates, with webhook-first state sync, a polling fallback, and live
        job progress streamed to clients over \textbf{SSE}.
  \item Built a service-provisioning engine that tracks each order through its
        lifecycle across seven service types, automating bare-metal setup over an
        HPE iLO Redfish wrapper and Celery-driven IP allocation.
  \item Architected a multi-tenant hosting and billing/ERP SaaS on \textbf{Django
        REST Framework} spanning 25+ apps and 230+ ViewSets under a unified
        \texttt{/api/} namespace.
  \item Designed a dual-gateway payment system (\textbf{Razorpay} +
        \textbf{Stripe}) with HMAC-SHA256 webhook idempotency to prevent duplicate
        charges, coordinating payment, invoicing, provisioning, and double-entry
        ledger reconciliation, plus Indian GST e-invoicing (EINV-2.1) through the
        NIC gateway with IRN generation and signed QR codes.
  \item Ran edge and cloud infrastructure: Cloudflare DNS/Pages/Workers,
        SPF/DKIM/DMARC mail, uptime monitoring, and deployments evolving from a
        \textbf{GCP} VM on single-node \textbf{Docker Swarm} with auto-rolling
        image updates to serverless, weighing cost, limits and operability.
  \item Planned service migrations and cutovers with written runbooks (a check
        and a rollback per step), architecture decision records, and a test-parity
        gate so every existing test is ported or explicitly dropped before release.
  \item Designed scheduled and queued background work with leases,
        heartbeats, retries and dead-letter queues so failed jobs surface
        instead of disappearing.
  \item Made local environments reproducible with \texttt{pg\_dump} seed
        snapshots, code-defined reference data (chart of accounts, tax rules,
        FX rates) and Alembic/Django migrations applied automatically on start.
