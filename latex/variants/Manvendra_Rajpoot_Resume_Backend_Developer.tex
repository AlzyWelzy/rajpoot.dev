  \item Designed a dual-gateway payment system (\textbf{Razorpay} +

        charges, coordinating payment, invoicing, provisioning, and double-entry

  \item Built an OAuth2/OpenID authorization server and \textbf{FastAPI}
        gateway to \textbf{Apache CloudStack} for VMs, volumes, networks and
        templates, with webhook-first state sync, a polling fallback, and live
        job progress streamed to clients over \textbf{SSE}.
  \item Secured the platform with RS512 \textbf{JWT} auth (kid-keyed JWKS,
        refresh-token rotation over HTTPOnly cookies), a 2FA flow over email OTP
        and RFC-6238 TOTP, and a 43-permission department-scoped RBAC.
  \item Shipped real-time notifications over a \textbf{Django Channels} 4 + Redis
        WebSocket server with JWT-authenticated async consumers, backed by a
        24-task \textbf{Celery} system (late-ack, worker-lost requeue).
  \item Built a service-provisioning engine that tracks each order through its
        lifecycle across seven service types, automating bare-metal setup over an
        HPE iLO Redfish wrapper and Celery-driven IP allocation.
  \item Set up end-to-end observability with \textbf{OpenTelemetry} tracing and a
        Prometheus/Grafana/Loki/Tempo stack, so failures across services could be
        traced to a single request.
  \item Built and open-sourced a type-safe Namecheap SSL/domain SDK
        (\textbf{httpx}, \textbf{Pydantic v2}, mypy-strict), published to PyPI ---
        \href{https://github.com/alzywelzy/namecheap-wrapper}{github.com/alzywelzy/namecheap-wrapper}.
  \item Planned service migrations and cutovers with written runbooks (a check
        and a rollback per step), architecture decision records, and a test-parity
        gate so every existing test is ported or explicitly dropped before release.
  \item Hardened sign-in with passkeys (\textbf{WebAuthn}), TOTP and
        recovery codes, device trust and rate limits, plus Web Push (RFC
        8291/8292) and AES-GCM encryption for sensitive fields.
  \item Designed scheduled and queued background work with leases,
        heartbeats, retries and dead-letter queues so failed jobs surface
        instead of disappearing.
  \item Eliminated N+1 queries via Prefetch/OuterRef/Exists across a dual
        async/sync database layer (asyncpg + psycopg) on SQLAlchemy 2.0 with
        connection pooling and keyset cursor pagination.
